**Modal feedback** (`qti-modal-feedback`) is feedback shown after the candidate
submits an [item](/concepts/assessment-item/), typically in a dialog or a
distinct block. It appears only when a feedback [outcome variable](/concepts/outcomes-and-scoring/)
matches its identifier.

## Purpose

Use modal feedback to react to the whole attempt — "Correct!", a worked solution,
or a hint — once [response processing](/concepts/response-processing/) has run.
For feedback woven into the body of the item, use
[`qti-feedback-block` / `qti-feedback-inline`](/reference/content/feedback-block-and-inline/).

## Place in the hierarchy

- **Parent:** the `qti-assessment-item` (a direct child, not inside the item body).
- **Children:** the feedback content itself sits in a required `qti-content-body`
  wrapper (optionally preceded by `qti-stylesheet` elements and followed by
  `qti-catalog-info`).
- **Driven by:** an outcome variable (commonly `FEEDBACK`) that response
  processing sets to this block's `identifier`.

## Attributes

<AttributesTable attributes={[
  { name: 'outcome-identifier', type: 'identifier', required: true, description: 'The outcome variable whose value selects this feedback.' },

## Example

<Example title="Show a message when the answer is correct">
```xml
<!-- in response processing -->
<qti-set-outcome-value identifier="FEEDBACK">
  <qti-base-value base-type="identifier">CORRECT</qti-base-value>
</qti-set-outcome-value>

<!-- direct child of qti-assessment-item -->
<qti-modal-feedback outcome-identifier="FEEDBACK" identifier="CORRECT" show-hide="show" title="Well done">
  <qti-content-body>
    <p>Correct — Amsterdam is the capital of the Netherlands.</p>
  </qti-content-body>
</qti-modal-feedback>
```
</Example>
