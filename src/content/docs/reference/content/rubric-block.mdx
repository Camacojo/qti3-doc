A **rubric block** (`qti-rubric-block`) is a block of content addressed to a
particular audience — the candidate, the scorer, a tutor, and so on. The delivery
engine shows or hides it depending on who is viewing the item or test.

## Purpose

Use a rubric block when content is meant for some audiences but not others:

- Instructions or context shown to the **candidate** during the attempt.
- Passage or stimulus material introducing a group of items.
- Scoring guidance shown only to the **scorer**, never to the candidate.

Because the `view` controls visibility, the same item can carry both candidate
instructions and private scoring notes.

## Place in the hierarchy

- **Parent:** the [item body](/concepts/item-body/), or an
  [assessment section](/concepts/assessment-test-and-sections/) (section-level
  rubric shown across the items it contains).
- **Children:** optional `qti-stylesheet` elements, a required `qti-content-body`,
  and an optional `qti-catalog-info`. The actual flow content — standard HTML plus
  QTI elements such as [`qti-printed-variable`](/reference/content/printed-variable/) —
  lives inside the `qti-content-body`.

## Example

<Example title="Candidate instructions and a private scoring note">
```xml
<qti-item-body>
  <qti-rubric-block view="candidate" use="instructions">
    <qti-content-body>
      <p>Read the passage below, then answer the question.</p>
    </qti-content-body>
  </qti-rubric-block>

  <qti-rubric-block view="scorer" use="scoring">
    <qti-content-body>
      <p>Award the mark only if the response names both causes.</p>
    </qti-content-body>
  </qti-rubric-block>

  <!-- interaction follows -->
</qti-item-body>
```
</Example>
