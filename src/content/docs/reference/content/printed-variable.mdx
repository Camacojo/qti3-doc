`qti-printed-variable` prints the current value of a variable into content. It is
how a question shows numbers that vary between candidates, or how feedback echoes
back a score.

## Purpose

- Show a **template variable** in a cloned item — e.g. "What is `A` + `B`?" where
  `A` and `B` differ per candidate. See
  [template declarations](/reference/processing/template-declaration/).
- Show an **outcome variable** in feedback — e.g. "You scored `SCORE` out of
  `MAXSCORE`." See [outcomes & scoring](/concepts/outcomes-and-scoring/).

## Place in the hierarchy

Appears as inline content anywhere flow content is allowed — inside the
[item body](/concepts/item-body/), a [rubric block](/reference/content/rubric-block/),
or a feedback block.

<AttributesTable attributes={[

## Example

<Example title="Echo the score back in feedback">
```xml
<qti-feedback-block outcome-identifier="FEEDBACK" identifier="DONE" show-hide="show">
  <p>You scored <qti-printed-variable identifier="SCORE"/> out of
     <qti-printed-variable identifier="MAXSCORE"/>.</p>
</qti-feedback-block>
```
</Example>
