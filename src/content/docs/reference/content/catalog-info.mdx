`qti-catalog-info` holds **alternative content** for parts of an item — a spoken
version, a glossary definition, a translation, sign-language video. At delivery,
the engine matches these alternatives against the candidate's
[Personal Needs & Preferences](/concepts/accessibility/) and substitutes or adds
content accordingly. This is the reference companion to the
[accessibility](/concepts/accessibility/) concept page.

## Structure

- `qti-catalog-info` contains one or more `qti-catalog`, each with an `id`.
- Content in the [item body](/concepts/item-body/) links to a catalog via
  `data-catalog-idref`.
- Each `qti-catalog` contains `qti-card` elements, one per alternative, tagged
  with a `support` type such as `glossary-on-screen`, `spoken`, or `keyword-translation`.

## Place in the hierarchy

In an item, `qti-catalog-info` is a **direct child of `qti-assessment-item`**,
placed after the `qti-item-body` — it is *not* part of the item body itself. The
body only carries the `data-catalog-idref` references; the catalog with the
alternative content sits at item level.

## Example

<Example title="A glossary alternative for a term">
```xml
<!-- inside qti-item-body -->
<p>The <span data-catalog-idref="cat-photosynthesis">photosynthesis</span> process…</p>

<!-- direct child of qti-assessment-item, after qti-item-body -->
<qti-catalog-info>
  <qti-catalog id="cat-photosynthesis">
    <qti-card support="glossary-on-screen">
      <qti-html-content>
        <div>The process by which plants convert light into chemical energy.</div>
      </qti-html-content>
    </qti-card>
  </qti-catalog>
</qti-catalog-info>
```
</Example>
