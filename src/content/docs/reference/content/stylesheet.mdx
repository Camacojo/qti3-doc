`qti-stylesheet` links an external CSS stylesheet to an [item](/concepts/assessment-item/)
so its content can be styled, much like `<link rel="stylesheet">` in HTML.

## Purpose

Use it to apply consistent presentation to an item's [body](/concepts/item-body/):
fonts, colours, layout. Prefer QTI's **shared CSS vocabulary** (standard class
names such as `qti-input-width-*`) for styling that stays portable across
delivery engines, and use a stylesheet for the rest.

## Place in the hierarchy

A child of `qti-assessment-item`, declared before the item body. It also appears
in the same position on `qti-assessment-test` (and on a stimulus, rubric blocks
and feedback elements, before their `qti-content-body`). The referenced
CSS file must be included in the [content package](/reference/packaging/content-package/)
and listed in the [manifest](/reference/packaging/imsmanifest/).

## Example

<Example title="Attach a stylesheet to an item">
```xml
<qti-assessment-item identifier="styled-item" title="Styled item" ...>
  <qti-stylesheet href="styles/item.css" type="text/css"/>
  <qti-item-body>
    <!-- content styled by item.css -->
  </qti-item-body>
</qti-assessment-item>
```
</Example>
