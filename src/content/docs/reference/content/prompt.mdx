`qti-prompt` holds the wording of a question — the instruction shown at the start
of an [interaction](/concepts/interactions-overview/). It is a small but
near-universal element: most interactions begin with one.

## Place in the hierarchy

An optional first child of an interaction (for example
[`qti-choice-interaction`](/reference/interactions/choice-interaction/)). It
contains inline content: text, and simple HTML such as `strong` or `em`.

A prompt is presentation only — it is not a choice and takes no identifier. It
has no attributes of its own beyond the
[shared QTI attributes](/reference/shared-attributes/) (`id`, `class`, `lang`,
`label`, `dir`, ARIA and `data-*`).

## Example

<Example title="A prompt inside a choice interaction">
```xml
<qti-choice-interaction response-identifier="RESPONSE" max-choices="1">
  <qti-prompt>Which planet is closest to the Sun?</qti-prompt>
  <qti-simple-choice identifier="A">Mercury</qti-simple-choice>
  <qti-simple-choice identifier="B">Venus</qti-simple-choice>
</qti-choice-interaction>
```
</Example>
