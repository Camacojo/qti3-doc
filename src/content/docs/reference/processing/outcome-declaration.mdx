The `qti-outcome-declaration` element declares an outcome variable: a value that is set during response processing (or test-level outcome processing) rather than supplied directly by the candidate. Outcome variables hold results such as a numeric score or a feedback identifier.

## Purpose

Use `qti-outcome-declaration` to declare each result value your item or test produces:

- **Scores.** By convention, the numeric result of an item is stored in an outcome called `SCORE`, with `MAXSCORE` holding its maximum possible value. Both are typically single floats.
- **Feedback control.** An outcome named `FEEDBACK` (a single or multiple identifier) is conventionally used to drive `qti-feedback-block` / `qti-feedback-inline` visibility.
- **Any custom result.** You can declare additional outcomes for partial scores, categories, or other computed values.

Response processing rules read and write these variables; the platform starts each with its default value (or the base-type's null value) before processing.

## Place in the hierarchy

`qti-outcome-declaration` is a direct child of `qti-assessment-item` (for item-level outcomes) or `qti-assessment-test` (for test-level outcomes). It sits alongside other variable declarations such as `qti-response-declaration`.

An outcome declaration may contain a single optional child:

- `qti-default-value` — wrapping one or more `qti-value` elements that define the outcome's initial value.

Unlike a response declaration, an outcome has no candidate-supplied value: it is populated only by processing rules such as those in `qti-response-processing`.

## Example

<Example title="Declaring SCORE, MAXSCORE, and FEEDBACK">

```xml
<qti-outcome-declaration identifier="SCORE" cardinality="single" base-type="float">
  <qti-default-value>
    <qti-value>0</qti-value>
  </qti-default-value>
</qti-outcome-declaration>

<qti-outcome-declaration identifier="MAXSCORE" cardinality="single" base-type="float"
                         normal-maximum="1">
  <qti-default-value>
    <qti-value>1</qti-value>
  </qti-default-value>
</qti-outcome-declaration>

<qti-outcome-declaration identifier="FEEDBACK" cardinality="single" base-type="identifier"/>
```

</Example>
