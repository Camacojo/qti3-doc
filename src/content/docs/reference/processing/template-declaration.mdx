The `qti-template-declaration` element declares a *template variable*: a variable whose value is set at item instantiation to produce a variation (clone) of the item. Template variables let a single item definition generate many parameterised versions, for example a maths question where the numbers change on each attempt.

## Purpose

Use `qti-template-declaration` when you want one item to yield multiple variations rather than authoring each variant by hand. Typical uses:

- Randomising the operands of a maths problem (for example the variables `A` and `B` in `A + B`).
- Selecting from a set of contexts, names, or wordings so the item reads differently each time.
- Driving conditional content or correct-response values that depend on the chosen variation.

The values of template variables are computed by [qti-template-processing](/reference/processing/response-processing/) when the item is instantiated. Once set, they can be referenced from response processing, from correct responses, and from the item body.

## Place in the hierarchy

`qti-template-declaration` appears directly inside `qti-assessment-item`, alongside `qti-response-declaration` and `qti-outcome-declaration`. It is populated by `qti-template-processing` at instantiation time. Like other variable declarations it may optionally contain a default value, and it binds a named template variable that the rest of the item can reference.

## Example

<Example title="Template variables A and B for a maths item">

```xml
<qti-assessment-item
  xmlns="http://www.imsglobal.org/xsd/imsqtiasi_v3p0"
  identifier="add-two-numbers"
  title="Add two numbers"
  adaptive="false"
  time-dependent="false">

  <qti-template-declaration
    identifier="A"
    cardinality="single"
    base-type="integer"
    math-variable="true"/>

  <qti-template-declaration
    identifier="B"
    cardinality="single"
    base-type="integer"
    math-variable="true"/>

  <qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="integer"/>

  <qti-outcome-declaration identifier="SCORE" cardinality="single" base-type="float"/>

  <!-- qti-template-processing assigns random values to A and B here -->

  <qti-item-body>
    <p>What is <qti-printed-variable identifier="A"/> + <qti-printed-variable identifier="B"/>?</p>
    <qti-text-entry-interaction response-identifier="RESPONSE" expected-length="3"/>
  </qti-item-body>

</qti-assessment-item>
```

</Example>
