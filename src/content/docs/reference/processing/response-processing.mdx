`qti-response-processing` is the container element inside an assessment item that holds the scoring logic. It maps the candidate's recorded responses onto outcome variables such as `SCORE`. It either references a standard response processing template through its `template` attribute, or contains an explicit set of response rules.

## Purpose

Use `qti-response-processing` when an item needs to compute outcomes from the responses a candidate has submitted. It is where the raw data captured by interactions is turned into scores and other outcome values.

There are two mutually exclusive ways to define the logic:

- **By template** — set the `template` attribute (or `template-location`) to a URI identifying a standard template such as match-correct or map-response. This is the simplest approach for common scoring patterns and needs no explicit rules.
- **By explicit rules** — omit the template and place child response rules directly inside the element. This is required whenever the scoring is too specific to be expressed by a built-in template.

An item declares at most one `qti-response-processing` element. For the conceptual background on how responses become outcomes, see the [response processing overview](/concepts/response-processing/).

## Place in the hierarchy

- **Parent:** `qti-assessment-item`. It follows the `qti-item-body`, whereas the variable declarations precede it.
- **Children:** when no template is used, a sequence of response rules such as `qti-set-outcome-value`, `qti-response-condition`, and `qti-exit-response`. When a template is used, the element is typically empty.
- **Variables it uses:** it reads the `qti-response-declaration` variables (for example `RESPONSE`) and writes to `qti-outcome-declaration` variables (for example `SCORE`). It does not itself bind to a single variable — it operates across all declared variables of the item.

## Example

<Example title="Referencing a standard template">

```xml
<qti-response-processing
  template="https://purl.imsglobal.org/spec/qti/v3p0/rptemplates/match_correct.xml"/>
```

</Example>

<Example title="Explicit rules that set SCORE">

```xml
<qti-response-processing>
  <qti-response-condition>
    <qti-response-if>
      <qti-match>
        <qti-variable identifier="RESPONSE"/>
        <qti-correct identifier="RESPONSE"/>
      </qti-match>
      <qti-set-outcome-value identifier="SCORE">
        <qti-base-value base-type="float">1</qti-base-value>
      </qti-set-outcome-value>
    </qti-response-if>
    <qti-response-else>
      <qti-set-outcome-value identifier="SCORE">
        <qti-base-value base-type="float">0</qti-base-value>
      </qti-set-outcome-value>
    </qti-response-else>
  </qti-response-condition>
</qti-response-processing>
```

</Example>
