The `qti-response-declaration` element declares a **response variable**: a container that holds a candidate's response to an interaction. It also carries the information needed to score that response, such as the correct answer and any mapping used for partial credit.

## Purpose

Use `qti-response-declaration` whenever an item collects a response from the candidate. Each interaction binds to exactly one response variable, and that variable must be declared before it can be used in response processing.

- Give every response variable a unique `identifier` that an interaction references through its `response-identifier` attribute.
- Record the intended answer in a `qti-correct-response` child so built-in response-processing templates (such as *match correct*) can score it.
- Attach a `qti-mapping` (or `qti-area-mapping` for point-based responses) to award partial credit by mapping individual response values to numeric contributions.

By convention the primary response variable of a simple item is named `RESPONSE`. Items with several interactions declare one response variable per interaction (for example `RESPONSE_1`, `RESPONSE_2`).

## Place in the hierarchy

`qti-response-declaration` is a direct child of `qti-assessment-item`. It appears alongside `qti-outcome-declaration` and `qti-template-declaration` and before the `qti-item-body` and response-processing sections.

- **Parent:** `qti-assessment-item`
- **Children (all optional, in order):**
  - `qti-default-value` — the value the variable holds before the candidate responds.
  - `qti-correct-response` — the correct answer, containing one or more `qti-value` elements.
  - `qti-mapping` — maps response values to numeric scores via `qti-map-entry` elements (attributes `map-key`, `mapped-value`), with `default-value`, `lower-bound`, and `upper-bound` on the mapping itself.
  - `qti-area-mapping` — the point/area equivalent of `qti-mapping`, used for graphic and point-selection responses.
- **Binds to:** the interaction whose `response-identifier` matches this declaration's `identifier`.

## Example

<Example title="Single-choice response with partial-credit mapping">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="identifier">
  <qti-correct-response>
    <qti-value>ChoiceA</qti-value>
  </qti-correct-response>
  <qti-mapping default-value="0" lower-bound="0" upper-bound="1">
    <qti-map-entry map-key="ChoiceA" mapped-value="1"/>
    <qti-map-entry map-key="ChoiceB" mapped-value="0.5"/>
    <qti-map-entry map-key="ChoiceC" mapped-value="0"/>
  </qti-mapping>
</qti-response-declaration>
```

</Example>
