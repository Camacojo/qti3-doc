**Operators** are expressions that take one or more sub-expressions as operands and combine their values into a single result. They form the working vocabulary of response processing: comparing a candidate's response to the correct answer, doing arithmetic on scores, and testing membership in containers all happen through operators.

## Purpose

Use an operator whenever a rule needs to *derive* a value from other values rather than simply read one. Operators nest freely, so the operand of one operator is typically another expression such as `qti-variable`, `qti-correct`, `qti-base-value`, or another operator.

- **Logical** operators build the boolean conditions used by `qti-response-if` and related rules.
- **Comparison** operators test one value against another and yield a single boolean.
- **Arithmetic** operators compute numeric results, most often to build a `SCORE`.
- **Container and string** operators inspect multi-valued responses and text.

Operators propagate NULL: if a required operand is NULL, most operators return NULL rather than a value. Test for this with `qti-is-null` before relying on a result.

## Operator reference

Operators are grouped below by the kind of work they do. Each takes its operands as child expressions. The most common operators are described here — the specification defines more.

### Logical operators

| Operator | Result | Description |
| -------- | ------ | ----------- |
| `qti-and` | boolean | True only if *every* boolean operand is true. Returns false if any operand is false; NULL propagates. |
| `qti-or` | boolean | True if *at least one* boolean operand is true. |
| `qti-not` | boolean | Negates a single boolean operand: true becomes false and vice versa. |

### Comparison operators

| Operator | Result | Description |
| -------- | ------ | ----------- |
| `qti-match` | boolean | True if the two operands are equal. Works for most base types and any cardinality (not `float` or `duration` — use `qti-equal` for numeric comparison), comparing containers as a whole (order matters for `ordered`). |
| `qti-equal` | boolean | True if two numeric operands are equal. `tolerance-mode` (`exact`, `absolute`, or `relative`) selects the comparison, `tolerance` supplies the tolerance bound(s), and `include-lower-bound` / `include-upper-bound` control whether the bounds themselves count as equal. |
| `qti-equal-rounded` | boolean | True if two numeric operands are equal after rounding to a given number of `significant-figures` or `decimal-places`. |
| `qti-gt` | boolean | True if the first numeric operand is strictly greater than the second. |
| `qti-gte` | boolean | True if the first numeric operand is greater than or equal to the second. |
| `qti-lt` | boolean | True if the first numeric operand is strictly less than the second. |
| `qti-lte` | boolean | True if the first numeric operand is less than or equal to the second. |
| `qti-inside` | boolean | True if the point operand falls inside the area defined by the operator's `shape` and `coords` attributes. Useful with the point responses of the graphic interactions. |

### Arithmetic operators

| Operator | Result | Description |
| -------- | ------ | ----------- |
| `qti-sum` | numeric | Adds all numeric operands and returns the total. |
| `qti-subtract` | numeric | Subtracts the second operand from the first. |
| `qti-product` | numeric | Multiplies all numeric operands together. |
| `qti-divide` | numeric | Divides the first operand by the second. |
| `qti-round` | integer | Rounds a single numeric operand to the nearest integer. |

### Container and string operators

| Operator | Result | Description |
| -------- | ------ | ----------- |
| `qti-member` | boolean | True if the first operand (a single value) is one of the values in the second operand (a container). |
| `qti-contains` | boolean | True if the first container contains the second container as a sub-sequence. |
| `qti-is-null` | boolean | True if its single operand is NULL (an unanswered response or empty container). |
| `qti-index` | any | Returns the value at the 1-based position `n` within an `ordered` container. |
| `qti-string-match` | boolean | True if two strings match; a `case-sensitive` attribute controls whether case is significant. |
| `qti-substring` | boolean | True if the second string operand contains the first as a substring, honouring `case-sensitive`. |
| `qti-pattern-match` | boolean | True if the string operand matches the regular expression given by the `pattern` attribute. |

## Example

<Example title="Combining operators to score a numeric response">

```xml
<qti-response-condition>
  <qti-response-if>
    <qti-and>
      <qti-gte>
        <qti-variable identifier="RESPONSE"/>
        <qti-base-value base-type="float">0.5</qti-base-value>
      </qti-gte>
      <qti-lt>
        <qti-variable identifier="RESPONSE"/>
        <qti-base-value base-type="float">1.5</qti-base-value>
      </qti-lt>
    </qti-and>
    <qti-set-outcome-value identifier="SCORE">
      <qti-base-value base-type="float">1</qti-base-value>
    </qti-set-outcome-value>
  </qti-response-if>
  <qti-response-else>
    <qti-set-outcome-value identifier="SCORE">
      <qti-base-value base-type="float">0</qti-base-value>
    </qti-set-outcome-value>
  </qti-response-else>
</qti-response-condition>
```

</Example>
