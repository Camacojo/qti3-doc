`qti-time-limits` constrains how long a candidate may (or must) spend. Like
[item session control](/reference/test/item-session-control/), it can appear on a
[test part](/reference/test/test-part/),
[section](/reference/test/assessment-section/), or
[item reference](/reference/test/assessment-item-ref/) — and also on the test
itself ([`qti-assessment-test`](/reference/test/assessment-test/)), the most
common case: a time limit for the whole test. An individual item can carry one
too, directly on `qti-assessment-item`.

## Attributes

<AttributesTable attributes={[
  { name: 'min-time', type: 'duration', description: 'Minimum time the candidate must spend before moving on (seconds).' },
  { name: 'max-time', type: 'duration', description: 'Maximum time allowed before the session is closed (seconds).' },
  { name: 'allow-late-submission', type: 'boolean', default: 'false', description: 'Whether a response submitted after max-time is still accepted.' },
]} caption="qti-time-limits attributes" />

## Example

<Example title="A 30-minute test part">
```xml
<qti-test-part identifier="part1" navigation-mode="linear" submission-mode="simultaneous">
  <qti-time-limits max-time="1800"/>
  <!-- sections -->
</qti-test-part>
```
</Example>
