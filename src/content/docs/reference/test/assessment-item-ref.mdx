`qti-assessment-item-ref` places an [item](/concepts/assessment-item/) into a
[section](/reference/test/assessment-section/) by pointing at its file. Items are
referenced, never inlined, so the same item can appear in many tests.

## Place in the hierarchy

- **Parent:** a [section](/reference/test/assessment-section/).
- **Children:** optional per-item [preconditions & branch rules](/reference/test/branch-rule-and-preconditions/),
  [`qti-item-session-control`](/reference/test/item-session-control/),
  [`qti-time-limits`](/reference/test/time-limits/) and one or more
  [`qti-weight`](/reference/test/weight/) elements.

## Attributes

<AttributesTable attributes={[
  { name: 'identifier', type: 'identifier', required: true, description: 'A test-unique identifier for this reference (distinct from the item’s own identifier).' },
  { name: 'href', type: 'URI', required: true, description: 'Relative path to the item XML within the package.' },
  { name: 'category', type: 'token list', description: 'Categories used to select or group items (e.g. by objective).' },
  { name: 'fixed', type: 'boolean', default: 'false', description: 'When true, the item keeps its position if the section is shuffled.' },
  { name: 'required', type: 'boolean', default: 'false', description: 'When true, the item must be included when the section makes a selection.' },
]} caption="qti-assessment-item-ref attributes" />

## Example

<Example title="A weighted item reference">
```xml
<qti-assessment-item-ref identifier="I1" href="items/essay.xml" category="writing">
  <qti-weight identifier="W1" value="2.0"/>
</qti-assessment-item-ref>
```
</Example>
