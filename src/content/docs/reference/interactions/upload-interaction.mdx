The `qti-upload-interaction` lets a candidate upload a file as their response. The candidate selects a document, image, spreadsheet, or other file from their device, and that file becomes the response bound to a single response variable of base type `file`.

## Purpose

Use `qti-upload-interaction` when the expected answer is a whole file rather than text typed into the item. Typical cases include:

- Submitting an essay, report, or document produced in an external application.
- Uploading a scanned worksheet, drawing, or photograph of hand-written work.
- Handing in a spreadsheet, source-code file, or other artefact created offline.

Because the response is an arbitrary file, this interaction is almost always **human-scored**: response processing cannot meaningfully inspect the file's contents, so scoring is deferred to a marker or examiner. You can constrain the kind of file the candidate is allowed to submit with the `type` attribute.

## Place in the hierarchy

- **Parent:** appears within the `qti-item-body` (directly or nested inside block-level content).
- **Children:** may contain an optional `qti-prompt` that gives the candidate instructions. It has no other interaction children.
- **Binds to:** a single response variable declared by a `qti-response-declaration` whose `identifier` matches `response-identifier`, with `cardinality="single"` and `base-type="file"`.

The interaction also accepts the shared attributes common to all interactions (such as `id`, `class`, `label`, and `data-*` attributes).

## Example

<Example title="Upload a completed report as a PDF">

```xml
<qti-response-declaration identifier="RESPONSE"
                          cardinality="single"
                          base-type="file"/>

<qti-outcome-declaration identifier="SCORE"
                         cardinality="single"
                         base-type="float">
  <qti-default-value>
    <qti-value>0</qti-value>
  </qti-default-value>
</qti-outcome-declaration>

<qti-item-body>
  <qti-upload-interaction response-identifier="RESPONSE"
                          type="application/pdf">
    <qti-prompt>
      Upload your completed lab report as a single PDF file.
    </qti-prompt>
  </qti-upload-interaction>
</qti-item-body>
```

</Example>
