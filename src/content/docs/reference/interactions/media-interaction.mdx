The `qti-media-interaction` presents an audio or video clip to the candidate and records how many times the media was played. The candidate's interaction with the media is captured as an integer count, which authors can use to require or limit playback.

## Purpose

Use `qti-media-interaction` when playback of a media clip is itself part of the task, for example:

- Listening comprehension items where a candidate must play an audio fragment.
- Video-based items where the recorded response is the number of times the candidate watched the clip.
- Any item where you want to require a minimum number of plays before an answer counts, or cap the number of plays allowed.

The media clip is embedded inside the interaction, and the response variable stores the number of times it was played rather than any answer the candidate types or selects.

## Place in the hierarchy

- **Parent:** the interaction is placed in the `qti-item-body` (directly or nested within block content).
- **Children:** it contains a single embedded media object. This is an HTML `object`, `audio`, or `video` element that references the audio or video resource.
- **Bound variable:** it binds to a `qti-response-declaration` named by its `response-identifier`. That response declaration must have cardinality `single` and base-type `integer`, since the recorded value is the number of plays.

## Example

<Example title="Video clip that must be played at least once">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="integer"/>

<qti-item-body>
  <p>Watch the short clip, then answer the questions that follow.</p>

  <qti-media-interaction response-identifier="RESPONSE"
                         autostart="false"
                         min-plays="1"
                         max-plays="3"
                         loop="false">
    <video width="480" height="270">
      <source src="clip.mp4" type="video/mp4"/>
      A short introductory video.
    </video>
  </qti-media-interaction>
</qti-item-body>
```

</Example>
