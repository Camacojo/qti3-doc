The `qti-hottext-interaction` presents a passage of running text in which certain words or phrases are marked as selectable "hot" spans. The candidate chooses one or more of these marked spans as the response.

## Purpose

Use this interaction when the answer lives inside a block of text and you want the candidate to identify it in context rather than type it or pick from a separate list.

- Ask learners to click the verb, the adjective, or the misspelled word in a sentence.
- Have candidates highlight the topic sentence or the claim in a paragraph.
- Mark several correct spans and require the candidate to find all of them.

Because the selectable regions sit inline within normal block content, the surrounding prose stays intact and readable while only the designated words become interactive.

## Place in the hierarchy

- **Parent:** the interaction appears in the item body (see [item body](/concepts/item-body/)).
- **Children:** block-level content (paragraphs, lists, and so on) that contains one or more `qti-hottext` elements. Each `qti-hottext` wraps the selectable word or phrase inline and carries its own `identifier`.
- **Binds to:** the response variable named by `response-identifier`, declared with a matching [response declaration](/reference/processing/response-declaration/).

The response has base type `identifier`. Use cardinality `single` when exactly one span may be chosen, and cardinality `multiple` when the candidate may select several spans. The value(s) recorded are the `identifier` values of the chosen `qti-hottext` elements.

Each nested `qti-hottext` element carries an `identifier` attribute whose value is what gets recorded in the response when that span is selected.

## Example

<Example title="Select the two adjectives in the sentence">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="multiple" base-type="identifier">
  <qti-correct-response>
    <qti-value>HT1</qti-value>
    <qti-value>HT3</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <qti-hottext-interaction response-identifier="RESPONSE" max-choices="2" min-choices="1">
    <qti-prompt>Click the two adjectives in the sentence below.</qti-prompt>
    <p>
      The <qti-hottext identifier="HT1">quick</qti-hottext>
      <qti-hottext identifier="HT2">fox</qti-hottext> jumped over the
      <qti-hottext identifier="HT3">lazy</qti-hottext>
      <qti-hottext identifier="HT4">dog</qti-hottext>.
    </p>
  </qti-hottext-interaction>
</qti-item-body>
```

</Example>
