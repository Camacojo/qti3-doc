The `qti-drawing-interaction` presents the candidate with a drawing surface laid over a background image. The candidate draws freely on top of that image, and the resulting picture is captured as the response.

## Purpose

Use `qti-drawing-interaction` when the task is to produce a freehand drawing rather than a selection or a text entry. Typical uses include:

- Annotating or marking up a diagram, map, or photograph.
- Sketching a shape, graph, or geometric construction over grid paper supplied as the background.
- Any open-ended visual task where the answer is a drawn image.

Because the response is a produced image file, the outcome is almost always **human-scored** (or reviewed) rather than machine-scored. There is no built-in way for response processing to inspect the drawing.

## Place in the hierarchy

`qti-drawing-interaction` is a block-level interaction that appears inside the `qti-assessment-item` body.

- **Parent:** the item body (or a block container within it).
- **Children:** a single HTML `object`, `img`, or `picture` element that supplies the background image to draw on (the spec deprecates `object` here in favour of `img`/`picture`). This element provides the image reference (the `src` of an `img`) and the canvas dimensions via its `width` and `height`.
- **Bound variable:** the interaction binds to the response variable named by its `response-identifier`. That response variable must be declared with **cardinality `single`** and **base-type `file`**, since the candidate's drawing is delivered as an image file.

## Example

<Example title="Annotate a map by drawing on it">

```xml
<qti-assessment-item
    xmlns="http://www.imsglobal.org/xsd/imsqtiasi_v3p0"
    identifier="draw-flood-zone"
    title="Mark the flood zone"
    adaptive="false"
    time-dependent="false">

  <qti-response-declaration identifier="RESPONSE"
                            cardinality="single"
                            base-type="file"/>

  <qti-outcome-declaration identifier="SCORE"
                           cardinality="single"
                           base-type="float">
    <qti-default-value>
      <qti-value>0</qti-value>
    </qti-default-value>
  </qti-outcome-declaration>

  <qti-item-body>
    <p>Using the drawing tools, shade the area of the map that lies within the flood zone.</p>

    <qti-drawing-interaction response-identifier="RESPONSE">
      <img src="images/river-map.png"
           alt="Map of the river valley"
           width="600"
           height="400"/>
    </qti-drawing-interaction>
  </qti-item-body>

  <!-- The drawing is delivered as a file and scored by a human reviewer. -->
</qti-assessment-item>
```

</Example>

:::note
A live demo is omitted here: the drawing surface needs a raster background image
(supplied via an `img` element) that this documentation does not bundle. See a
working example in the [qti-components Storybook](https://qti-components.citolab.nl).
:::
