The `qti-order-interaction` presents a set of choices to the candidate and asks them to arrange those choices into the correct sequence. The candidate's response is the ordered list of the choices they selected.

## Purpose

Use `qti-order-interaction` when the skill you want to assess is the correct *ordering* of items rather than simply selecting or matching them. Typical uses include:

- Placing historical events in chronological order.
- Sequencing the steps of a procedure or process.
- Ranking items from smallest to largest, or from least to most.
- Arranging words into a grammatically correct sentence.

Each candidate response is a single ordering of the available choices, so this interaction is a good fit whenever there is exactly one correct sequence to be judged.

## Place in the hierarchy

`qti-order-interaction` is a block-level interaction that appears inside the `qti-item-body` of an assessment item.

- **Parent:** `qti-item-body` (or a block container within it).
- **Children:** one or more `qti-simple-choice` elements, each carrying a unique `identifier`.
- **Bound variable:** it binds to the `qti-response-declaration` named by its `response-identifier`.

The associated response variable must be declared with cardinality `ordered` and base-type `identifier`. The `qti-correct-response` is the ordered list of the child `qti-simple-choice` identifiers in their intended sequence.

## Example

<Example title="Order events in chronological sequence">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="ordered" base-type="identifier">
  <qti-correct-response>
    <qti-value>eventA</qti-value>
    <qti-value>eventB</qti-value>
    <qti-value>eventC</qti-value>
    <qti-value>eventD</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <qti-order-interaction response-identifier="RESPONSE" shuffle="true" orientation="vertical">
    <qti-prompt>Place these events in chronological order, earliest first.</qti-prompt>
    <qti-simple-choice identifier="eventA">Invention of the printing press</qti-simple-choice>
    <qti-simple-choice identifier="eventB">The French Revolution</qti-simple-choice>
    <qti-simple-choice identifier="eventC">The first powered flight</qti-simple-choice>
    <qti-simple-choice identifier="eventD">The first Moon landing</qti-simple-choice>
  </qti-order-interaction>
</qti-item-body>
```
