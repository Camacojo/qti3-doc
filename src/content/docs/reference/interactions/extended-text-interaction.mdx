The `qti-extended-text-interaction` presents a multi-line text area in which the candidate types a longer free-text response, such as an essay, a short explanation, or a worked-out argument. It is the long-form counterpart to the single-line `qti-text-entry-interaction`.

## Purpose

Use `qti-extended-text-interaction` when you want the candidate to compose a substantial written answer rather than a single word or number.

- Essay questions and open-ended writing prompts.
- Explanations, justifications, or step-by-step reasoning.
- Any response that naturally spans multiple lines or paragraphs.

Extended-text responses are usually **human-scored**: the item typically has no automatic correct answer, so there is no `qti-correct-response` in the response declaration and no automatic response processing. Scoring is deferred to a human marker (or an external scoring service). You can still supply hints to renderers, such as an expected length or number of lines.

## Place in the hierarchy

- **Parent:** appears within the `qti-item-body` (directly or nested inside block-level content).
- **Children:** may contain an optional `qti-prompt` element that gives the question text or instructions shown to the candidate.
- **Bound variable:** the `response-identifier` attribute binds the interaction to a `qti-response-declaration`, usually with base-type `string` (the spec also allows `integer` and `float`). Its cardinality is `single` (one block of text) or `multiple`/`ordered` (several separate strings, for example when `max-strings` allows more than one entry to be captured as distinct values).

## Example

<Example title="Essay prompt (human-scored)">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="string"/>

<qti-outcome-declaration identifier="SCORE" cardinality="single" base-type="float">
  <qti-default-value>
    <qti-value>0</qti-value>
  </qti-default-value>
</qti-outcome-declaration>

<qti-item-body>
  <qti-extended-text-interaction
    response-identifier="RESPONSE"
    expected-lines="10"
    expected-length="800"
    format="plain">
    <qti-prompt>
      Explain how photosynthesis converts light energy into chemical energy.
      Use at least two examples to support your answer.
    </qti-prompt>
  </qti-extended-text-interaction>
</qti-item-body>
```

The response variable is declared with base-type `string` and no correct response, so the answer is stored for a human marker. The `SCORE` outcome is set during marking rather than by automatic response processing.

</Example>
