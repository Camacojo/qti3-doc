The `qti-hotspot-interaction` presents a background image on which one or more predefined regions (hotspots) are defined. The candidate responds by selecting one or more of these regions. It is the graphic counterpart of the `qti-choice-interaction`: the candidate picks from a fixed set of choices, but here each choice is a clickable area of an image.

## Purpose

Use `qti-hotspot-interaction` when the answer is best expressed as a location on a picture, diagram, map, or figure, and the acceptable locations are known in advance.

- Identifying a part of a diagram (for example, selecting an organ on an anatomical illustration).
- Choosing a country or region on a map.
- Picking the correct area of a photograph or chart.

Each selectable region is declared as a `qti-hotspot-choice` with a `shape` and `coords`. Because the regions are predefined, this interaction is appropriate when you can enumerate the valid choices. When the candidate must click an arbitrary point rather than choose from fixed regions, use the [qti-select-point-interaction](/reference/interactions/select-point-interaction/) instead.

## Place in the hierarchy

- **Parent:** appears in the item body ([qti-item-body](/concepts/item-body/)), like other interactions.
- **Children:** a background image expressed as an HTML `object`, `img`, or `picture` element, followed by one or more `qti-hotspot-choice` elements. Each `qti-hotspot-choice` carries an `identifier`, a `shape`, and `coords`.
- **Binds to:** the response variable named by its `response-identifier`. The bound [qti-response-declaration](/reference/processing/response-declaration/) has base-type `identifier`. Use cardinality `single` when at most one hotspot may be selected, and cardinality `multiple` when several may be selected. The response value(s) are the `identifier`(s) of the chosen `qti-hotspot-choice` element(s).

The `shape` attribute of each `qti-hotspot-choice` accepts the following values, each with its own `coords` format (a comma-separated list of pixel values):

- `circle` — `centerX, centerY, radius`
- `default` — the entire image area (no coordinates needed)
- `ellipse` — `centerX, centerY, hRadius, vRadius` (deprecated)
- `poly` — a sequence of `x, y` point pairs describing the polygon vertices
- `rect` — `left-x, top-y, right-x, bottom-y`

Each `qti-hotspot-choice` child carries its own attributes: `identifier` (the value reported to the response variable), `shape`, and `coords`.

## Example

Note the different `shape` values (`circle`, `rect`, `poly`, `ellipse`) and their
`coords`, and that either an `img` or an `object` element can supply the background image.

<Tabs>
  <TabItem label="Single region">
```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="identifier">
  <qti-correct-response>
    <qti-value>HS_CAPITAL</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <p>Click on the location of the capital city.</p>
  <qti-hotspot-interaction response-identifier="RESPONSE" max-choices="1">
    <img src="images/map.png" alt="Map of the region" width="480" height="360"/>
    <qti-hotspot-choice identifier="HS_CAPITAL" shape="circle" coords="120,90,15"/>
    <qti-hotspot-choice identifier="HS_PORT" shape="circle" coords="300,210,15"/>
    <qti-hotspot-choice identifier="HS_MOUNTAIN" shape="rect" coords="360,20,440,80"/>
  </qti-hotspot-interaction>
</qti-item-body>
```
  </TabItem>
  <TabItem label="Multiple regions">
```xml
<qti-response-declaration identifier="RESPONSE" cardinality="multiple" base-type="identifier">
  <qti-correct-response>
    <qti-value>HS_A</qti-value>
    <qti-value>HS_C</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <p>Select all the regions shaded in the diagram.</p>
  <qti-hotspot-interaction response-identifier="RESPONSE" max-choices="0" min-choices="1">
    <object type="image/png" data="images/diagram.png" width="500" height="400">Diagram</object>
    <qti-hotspot-choice identifier="HS_A" shape="poly" coords="10,10,90,10,50,90"/>
    <qti-hotspot-choice identifier="HS_B" shape="ellipse" coords="200,150,60,40"/>
    <qti-hotspot-choice identifier="HS_C" shape="rect" coords="320,60,420,160"/>
  </qti-hotspot-interaction>
</qti-item-body>
```
  </TabItem>
</Tabs>

:::note
A live demo is omitted here: outside a full item/player context the
`@citolab/qti-components` renderer draws the clickable regions in a shadow layer
whose host height collapses, so the hotspots overlap the surrounding content. For
clicking a free coordinate on an image that renders cleanly here, see
[qti-select-point-interaction](/reference/interactions/select-point-interaction/);
for a working hotspot example see the
[qti-components Storybook](https://qti-components.citolab.nl).
:::
