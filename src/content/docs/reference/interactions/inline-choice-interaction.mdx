The `qti-inline-choice-interaction` presents a set of choices as a dropdown (combo box) embedded directly within a sentence or other running text. The candidate selects exactly one option from the list.

## Purpose

Use this interaction when you want the candidate to complete a sentence or statement by picking a single answer from a compact list, without breaking the flow of the surrounding text.

- Fill-in-the-blank style questions where the answer comes from a fixed set of options.
- Cloze passages where one word or phrase in a sentence must be chosen from alternatives.
- Situations where a block-level `qti-choice-interaction` would be too visually disruptive.

Because it renders inline, it is well suited to text-heavy items. For selecting one option from a prominent, block-level list, use the [choice interaction](/reference/interactions/choice-interaction/) instead.

## Place in the hierarchy

- **Parent:** appears inline within the flow content of `qti-item-body` (for example inside a `p` or other text element).
- **Children:** one or more `qti-inline-choice` elements, each carrying an `identifier` that names the option.
- **Binds to:** the response variable named by `response-identifier`. That variable is declared with a `qti-response-declaration` of cardinality `single` and base-type `identifier`.

Each child `qti-inline-choice` carries a required `identifier` attribute (the value stored in the response variable when that option is chosen).

## Example

<Example title="Choose the correct word inside a sentence">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="identifier">
  <qti-correct-response>
    <qti-value>river</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <p>
    The Amazon is the largest
    <qti-inline-choice-interaction response-identifier="RESPONSE" shuffle="true" required="true">
      <qti-inline-choice identifier="lake">lake</qti-inline-choice>
      <qti-inline-choice identifier="river">river</qti-inline-choice>
      <qti-inline-choice identifier="desert">desert</qti-inline-choice>
    </qti-inline-choice-interaction>
    in the world by discharge volume.
  </p>
</qti-item-body>
```

  `} />
</Example>
