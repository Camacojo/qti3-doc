The `qti-graphic-gap-match-interaction` presents a background image together with a set of draggable image tiles. The candidate answers by dragging each image tile onto one of the hotspots defined on the background image.

## Purpose

Use this interaction when the association the candidate must make is inherently visual: both the choices and the drop targets are images or regions of an image.

- Labelling a diagram by dragging labels (as images) onto hotspots on a map, chart, or illustration.
- Placing objects in their correct location on a scene or floor plan.
- Matching visual symbols to positions on a background image.

It is the graphical counterpart of the [`qti-gap-match-interaction`](/reference/interactions/gap-match-interaction/): instead of inline text gaps, the drop targets are hotspots positioned on an image, and the choices are draggable image tiles rather than text.

## Place in the hierarchy

- **Parent:** the interaction lives in the item body (`qti-item-body`).
- **Children:**
  - A background `qti-object` element that defines the image on which the hotspots are positioned. This is a direct child of the interaction (not wrapped in a gap image).
  - One or more `qti-gap-img` elements, each wrapping a `qti-object` that renders the draggable image tile. Each `qti-gap-img` carries an `identifier` and a `match-max`.
  - One or more `qti-associable-hotspot` elements that act as the drop targets. Each has an `identifier`, a `shape`, `coords`, and a `match-max`.
- **Variable binding:** it binds to a response variable (named by `response-identifier`) declared with a `qti-response-declaration`. The response has cardinality `multiple` and base-type `directedPair`, where each pair associates a `qti-gap-img` identifier with a `qti-associable-hotspot` identifier (in that order: gap image then hotspot).

## Example

<Example title="Label the diagram by dragging images onto hotspots">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="multiple" base-type="directedPair">
  <qti-correct-response>
    <qti-value>IMG_HEART H1</qti-value>
    <qti-value>IMG_LUNG H2</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <qti-graphic-gap-match-interaction response-identifier="RESPONSE" shuffle="true" max-associations="2">
    <qti-prompt>Drag each label onto the correct organ.</qti-prompt>
    <qti-object type="image/png" data="images/body-diagram.png" width="480" height="360"/>
    <qti-gap-img identifier="IMG_HEART" match-max="1">
      <qti-object type="image/png" data="images/label-heart.png" width="80" height="24"/>
    </qti-gap-img>
    <qti-gap-img identifier="IMG_LUNG" match-max="1">
      <qti-object type="image/png" data="images/label-lung.png" width="80" height="24"/>
    </qti-gap-img>
    <qti-associable-hotspot identifier="H1" shape="circle" coords="180,140,25" match-max="1"/>
    <qti-associable-hotspot identifier="H2" shape="circle" coords="300,150,25" match-max="1"/>
  </qti-graphic-gap-match-interaction>
</qti-item-body>
```

</Example>
