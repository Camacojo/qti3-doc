The `qti-slider-interaction` presents a slider control that lets the candidate pick a single numeric value along a continuous range bounded by a lower and an upper value.

## Purpose

Use a slider interaction when the candidate should choose a numeric value within a known range by dragging a handle rather than typing a number.

- Good for estimation tasks, ratings, and questions where a value on a scale is more intuitive than free text.
- The candidate always selects exactly one value (single cardinality) somewhere between the `lower-bound` and `upper-bound`.
- Use the `step` attribute to constrain selection to discrete increments (for example whole numbers or steps of 0.5).

If you need the candidate to type a precise number, prefer a [text entry interaction](/reference/interactions/text-entry-interaction/) instead.

## Place in the hierarchy

- **Parent:** the `qti-item-body` (or a nested content element) of an [assessment item](/concepts/assessment-item/).
- **Children:** an optional `qti-prompt` element that supplies the question text shown with the slider.
- **Binds to:** the response variable named by `response-identifier`. The matching [response declaration](/reference/processing/response-declaration/) must have `cardinality="single"` and `base-type="float"` or `base-type="integer"`.

Use `base-type="integer"` together with an integer `step` when only whole-number values are meaningful; otherwise use `base-type="float"`.

## Example

<Example title="Estimate a temperature on a 0–100 scale">

```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="integer">
  <qti-correct-response>
    <qti-value>37</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <qti-slider-interaction
      response-identifier="RESPONSE"
      lower-bound="0"
      upper-bound="100"
      step="1"
      step-label="true"
      orientation="horizontal">
    <qti-prompt>What is the normal body temperature in degrees Celsius? Drag the slider to your estimate.</qti-prompt>
  </qti-slider-interaction>
</qti-item-body>
```

</Example>

## Try it

<QtiDemo markup={`
  <qti-slider-interaction response-identifier="RESPONSE" lower-bound="0" upper-bound="100" step="1">
    <qti-prompt>Estimate: what percentage of the Earth's surface is covered by water?</qti-prompt>
  </qti-slider-interaction>
`} />
