The `qti-end-attempt-interaction` renders a submit-like button that lets the candidate end the current attempt on demand. Pressing it triggers response processing, which is most commonly used in adaptive items to reveal feedback or hints without ending the whole item session.

## Purpose

Use this interaction when the candidate should be able to deliberately end an attempt and have the item respond immediately. It is designed mainly for **adaptive items**, where each attempt can produce updated feedback, a hint, or a revised prompt.

- Give the candidate an explicit "check my answer", "show hint", or "next step" control.
- Trigger [response processing](/concepts/response-processing/) so that [feedback](/concepts/feedback/) can be shown between attempts.
- Support multi-step adaptive flows where the outcome of one attempt shapes the next.

The bound response variable records simply whether the button was pressed during the attempt. Response processing can then branch on that value to decide what to reveal.

## Place in the hierarchy

- **Parent:** appears in the [item body](/concepts/item-body/), typically alongside the interaction whose answer is being checked.
- **Children:** none. The button label is provided through the `title` attribute rather than child content.
- **Binds to:** a [response declaration](/reference/processing/response-declaration/) with **base-type `boolean`** and **cardinality `single`**. The variable is set to `true` when the button is pressed during the attempt and `false` otherwise.

## Example

<Example title="An end-attempt button that reveals a hint in an adaptive item">

```xml
<qti-response-declaration identifier="RESPONSE" base-type="string" cardinality="single"/>
<qti-response-declaration identifier="HINTREQUEST" base-type="boolean" cardinality="single"/>

<qti-outcome-declaration identifier="FEEDBACK" base-type="identifier" cardinality="single"/>

<qti-item-body>
  <p>
    <qti-text-entry-interaction response-identifier="RESPONSE" expected-length="10"/>
  </p>

  <qti-end-attempt-interaction
    response-identifier="HINTREQUEST"
    title="Show hint"/>

  <p>
    <qti-feedback-inline outcome-identifier="FEEDBACK" identifier="HINT" show-hide="show">
      Remember to convert to metres before adding.
    </qti-feedback-inline>
  </p>
</qti-item-body>
```

</Example>
