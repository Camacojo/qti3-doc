The **choice interaction** presents the candidate with a set of choices and asks
them to select one (single choice) or several (multiple choice). It is the most
widely used interaction in QTI.

## Purpose

Use a choice interaction when the candidate picks from a predefined list:
multiple-choice and multiple-response questions, true/false, and yes/no items.

- Set `max-choices="1"` for single choice (radio-button behaviour).
- Set `max-choices="0"` (unlimited) or a higher number for multiple response
  (checkbox behaviour).

## Place in the hierarchy

- **Parent:** [`qti-item-body`](/concepts/item-body/) (or a block within it).
- **Children:** an optional [`qti-prompt`](/concepts/item-body/), followed by one
  or more `qti-simple-choice` elements.
- **Bound to:** a [`qti-response-declaration`](/reference/processing/response-declaration/)
  with `base-type="identifier"`. Cardinality is `single` for one choice and
  `multiple` when more than one is allowed.

## Attributes

<AttributesTable shared attributes={[
  { name: 'response-identifier', type: 'identifier', required: true, description: 'Identifier of the bound <code>qti-response-declaration</code>.' },
  { name: 'max-choices', type: 'integer', default: '1', description: 'Maximum choices the candidate may select. <code>0</code> means no limit.' },
  { name: 'min-choices', type: 'integer', default: '0', description: 'Minimum choices required for a valid response.' },
  { name: 'shuffle', type: 'boolean', default: 'false', description: 'Randomise the order of choices at delivery. Use <code>fixed</code> on a choice to pin it in place.' },
  { name: 'orientation', type: 'vertical | horizontal', default: 'vertical', description: 'Layout hint for how choices are arranged.' },
]} caption="qti-choice-interaction attributes" />

Each `qti-simple-choice` takes an `identifier` (required) and an optional
`fixed="true"` to exclude it from shuffling.

## Example

Switch between single choice (`max-choices="1"`, radio buttons) and multiple
response (`cardinality="multiple"`, checkboxes). The demos below are interactive —
rendering is powered by [`@citolab/qti-components`](/onboarding/open-source-packages/).

<Tabs>
  <TabItem label="Single choice">
```xml
<qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="identifier">
  <qti-correct-response>
    <qti-value>ChoiceC</qti-value>
  </qti-correct-response>
</qti-response-declaration>

<qti-item-body>
  <qti-choice-interaction response-identifier="RESPONSE" max-choices="1" shuffle="false">
    <qti-prompt>What is the capital of the Netherlands?</qti-prompt>
    <qti-simple-choice identifier="ChoiceA">Rotterdam</qti-simple-choice>
    <qti-simple-choice identifier="ChoiceB">The Hague</qti-simple-choice>
    <qti-simple-choice identifier="ChoiceC">Amsterdam</qti-simple-choice>
  </qti-choice-interaction>
</qti-item-body>
```
