An **assessment item** is a single question: everything needed to present it,
capture a response, and score it. In QTI it is the element `qti-assessment-item`,
and it is the smallest piece of content you can deliver on its own.

## Anatomy of an item

Every item is built from the same parts, in this order:

1. **Variable declarations** — what data the item tracks:
   [response](/reference/processing/response-declaration/),
   [outcome](/reference/processing/outcome-declaration/), and
   [template](/reference/processing/template-declaration/) declarations. See
   [Variables & declarations](/concepts/variables-and-declarations/).
2. **Item body** — the content shown to the candidate, including one or more
   [interactions](/concepts/interactions-overview/). See [Item body](/concepts/item-body/).
3. **Response processing** — the rules that turn the response into outcomes. See
   [Response processing](/concepts/response-processing/).
4. **Feedback** (optional) — content shown based on outcomes. See [Feedback](/concepts/feedback/).

## Key attributes

- `identifier` — a unique identifier for the item.
- `title` — a human-readable title.
- `adaptive` — `true` if the item changes its behaviour across attempts (adaptive
  items score progressively); `false` for the common non-adaptive case.
- `time-dependent` — `true` if timing affects scoring.

## A complete minimal item

<Example title="A scored single-choice item, end to end">
```xml
<qti-assessment-item
  xmlns="http://www.imsglobal.org/xsd/imsqtiasi_v3p0"
  identifier="capital-nl" title="Capital of the Netherlands"
  adaptive="false" time-dependent="false">

  <qti-response-declaration identifier="RESPONSE" cardinality="single" base-type="identifier">
    <qti-correct-response>
      <qti-value>ChoiceC</qti-value>
    </qti-correct-response>
  </qti-response-declaration>

  <qti-outcome-declaration identifier="SCORE" cardinality="single" base-type="float">
    <qti-default-value><qti-value>0</qti-value></qti-default-value>
  </qti-outcome-declaration>

  <qti-item-body>
    <qti-choice-interaction response-identifier="RESPONSE" max-choices="1">
      <qti-prompt>What is the capital of the Netherlands?</qti-prompt>
      <qti-simple-choice identifier="ChoiceA">Rotterdam</qti-simple-choice>
      <qti-simple-choice identifier="ChoiceB">The Hague</qti-simple-choice>
      <qti-simple-choice identifier="ChoiceC">Amsterdam</qti-simple-choice>
    </qti-choice-interaction>
  </qti-item-body>

  <qti-response-processing
    template="https://purl.imsglobal.org/spec/qti/v3p0/rptemplates/match_correct.xml"/>
</qti-assessment-item>
```
</Example>

Read this top to bottom: it declares a `RESPONSE` variable with a correct answer,
a `SCORE` outcome, shows three choices, and scores with the built-in
`match_correct` [template](/reference/processing/built-in-templates/).
