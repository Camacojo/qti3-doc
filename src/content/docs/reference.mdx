This is the element-level reference for QTI 3.0. Every element or topic has its
own focused, shareable page following one template: *purpose → place in the
hierarchy → attributes → example → cross-references → spec link*.

New to QTI? Start with the [core concepts](/concepts/assessment-item/) instead —
they explain the ideas these elements implement.
