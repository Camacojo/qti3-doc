[`kennisnet/php-qti3`](/onboarding/open-source-packages/) is a PHP library for
working with QTI 3.0 on the server: importing and exporting
[packages](/concepts/content-packaging/), validating them, editing tests, and
running [response processing](/concepts/response-processing/) to calculate
outcomes.

## Install

<Example title="Install (Composer)">
```bash
composer require wikiwijs/php-qti3
```
</Example>

## Set up the QtiClient

The library exposes a `QtiClient` service container. It expects three
implementations — a Flysystem-based package factory, plus a PSR-18/PSR-17-based
resource validator and resource downloader — for which the library ships
defaults. Their dependencies are only Composer *suggests*, so you must
additionally install them yourself:

<Example title="Install the default implementations' dependencies">
```bash
composer require league/flysystem symfony/http-client nyholm/psr7
```
</Example>

<Example title="Initialise the client">
```php
use League\Flysystem\Local\LocalFilesystemAdapter;
use League\Flysystem\Filesystem;
use Qti3\QtiClient;
use Qti3\Package\Filesystem\FlysystemPackageFactory;
use Qti3\Package\Validator\Resource\PsrHttpClientResourceValidator;
use Qti3\Package\Downloader\Resource\PsrHttpClientResourceDownloader;
use Qti3\Package\Filesystem\FileSystemUtils;

$filesystem = new Filesystem(new LocalFilesystemAdapter('/tmp/qti-data'));
$httpClient = new \Symfony\Component\HttpClient\Psr18Client();
$requestFactory = new \Nyholm\Psr7\Factory\Psr17Factory();

$qtiClient = new QtiClient(
    new FlysystemPackageFactory($filesystem),
    new PsrHttpClientResourceValidator($httpClient, $requestFactory),
    new PsrHttpClientResourceDownloader(new FileSystemUtils(), $httpClient, $requestFactory, '/tmp/qti-data'),
);
```
</Example>

## Import a package

<Example title="Read a package from a ZIP or a folder">
```php
$reader = $qtiClient->getQtiPackageReader();

$package = $reader->fromZip('/tmp/qti3.zip');
// or
$package = $reader->fromFilesystem('/tmp/folder');
// $package is a Qti3\Package\Model\QtiPackage
```
</Example>

You can also validate a package (`getQtiPackageValidator()`), edit its items in
place (`getPackageEditor()`), and write it back out to a ZIP or folder. To
validate against an external validator service instead of the built-in XSD
check, see [Validate QTI content](/guides/validating-qti/#validating-from-php-qti3).

## Score a response

Response processing takes the item XML and a map of candidate responses, and
returns the resulting outcome values.

<Example title="Run response processing (UC-I3)">
```php
// $responses maps response-identifier => value, e.g. ['RESPONSE' => 'ChoiceC']
$processor  = $qtiClient->getResponseProcessor();
$itemState  = $processor->initItemState($itemXml);
$processor->processResponses($itemState, $responses);

$outcomes = $itemState->outcomeSet->outcomes;
// associative array: outcome-identifier => value, e.g. ['SCORE' => 1.0]
```
</Example>

## Supported interactions

The parser supports exactly these interaction types; others (inline-choice,
associate, slider, media, the graphic interactions, …) throw a `ParseError`:

`choice` · `text-entry` · `extended-text` · `gap-match` · `hotspot` · `hottext` ·
`match` · `order` · `select-point`.

Each interaction reference page shows this support with a badge at the top.
